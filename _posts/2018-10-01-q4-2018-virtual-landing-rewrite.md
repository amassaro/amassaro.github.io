The end of 2018 brings a significant architectural change.

## New Stack for Virtual Landing

The virtual landing platform is getting a rewrite. The new version uses PHP for the backend API, TypeScript for the frontend, and Docker for deployment. It's a modern stack that should provide more flexibility than the previous C#-based approach.

## Why the Rewrite?

Several factors drove this decision: easier deployment, better hosting options, and the ability to iterate faster. The previous version worked well but was tied to Windows infrastructure. The new version can run anywhere.

## Frontend and Admin Interfaces

The rewrite includes separate frontend and admin interfaces. The admin panel lets users manage their landing pages and campaigns. The frontend delivers those pages to end users. Clean separation of concerns.

## Year in Review

2018 was eclectic - cryptocurrency, molecular sketching, and a major platform rewrite. Sometimes the most interesting years are the ones without a single theme.
