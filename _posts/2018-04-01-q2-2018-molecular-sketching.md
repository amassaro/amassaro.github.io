Spring brings an unexpected domain: chemistry software.

## Ketcher - Molecular Sketching

I've been exploring Ketcher, an open-source web-based molecule sketcher. It's fascinating software that lets chemists draw molecular structures in a browser. I forked the project to explore customizations and integrations.

## New Domain, Same Principles

Working with scientific software is humbling. The domain knowledge required is immense - I'm learning about chemical notation, bond types, and molecular representation formats. But underneath it all, the software engineering principles remain the same: clean APIs, good UX, maintainable code.

## Coin Control Wrapping Up

The Linda Coin Control script from Q1 has reached a stable state. It served its purpose as a learning exercise and continues to work for its intended use case.
